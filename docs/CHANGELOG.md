# 版本历史

## 1.7.0

- 插件（Codex）：开关、移除声明、声明新插件（市场必须已存在）
- 悬浮注释：MCP / 插件 / bundle / 补丁 悬停显示用途说明、启动命令、配置文件路径
- MCP 与插件共用同一套「精确改段」逻辑

## 1.6.0

- MCP 开关：改 `enabled` 一行，不删除即可临时禁用
- 目标段没有 `enabled` 行时自动插入；重复设置同一状态不写文件、不产生备份

## 1.5.0

- MCP 移除：精确删除 `[mcp_servers.名字]` 整段（含 `.env` 子段），其余内容逐字节保留
- 删除后列出被删内容，并提供回滚入口

## 1.4.0

- 从 GitHub 安装 MCP 到 Codex：读 README 识别 `npx` / `uvx` / `docker` 启动命令，给出候选由用户确认
- 写配置前自动备份，支持一键回滚（回滚前再备份一次）
- 拒绝重名、非法名称、含换行或引号的参数

## 1.3.0

- 新增「MCP / 插件 / 扩展」面板：扫描 Codex `config.toml`、DSH `cordis.patch.yml` / `package.json`、Claude Code 的 agents/commands
- 只读展示，不改任何配置

## 1.2.2

- GitHub 搜索结果：显示真实 `total_count`，单页 15 → 30 条，0 结果自动降级为 OR 重查
- 搜索面板加宽（330px → 560px），支持 `#q=关键词` 直接打开

## 1.2.1

- 对话框置顶修复：文件夹选择框不再被浏览器窗口挡住
- 移除启动时多余的字符，修复 `ReferenceError`

## 1.2.0

- 修复设置保存时丢失自定义项目技能目录
- 保存设置不再把端口重置为默认值

## 1.1.0

- 本地接口加令牌鉴权与 Host 校验
- 拒绝符号链接 / 目录联接，避免越界读写
- zip 解压加上限（单文件 64 MB / 总计 256 MB）
- 所有子进程 `windowsHide`，不弹控制台

## 1.0.0

- 首个版本：多智能体技能扫描、开关、删除到回收站、GitHub 搜索与安装
