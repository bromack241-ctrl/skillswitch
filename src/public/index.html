智能体与技能目录设置

每个智能体对应一个或多个「技能目录」。技能 = 一个包含 SKILL.md 文件的文件夹。
切换开关时，会把该文件夹内的 SKILL.md 重命名为 SKILL.md.disabled（关闭）或改回（开启），不会删除任何文件。

项目目录（扫描项目级技能）

在这里填入你的项目文件夹，软件会自动扫描其中的项目级技能目录（如 .claude/skills、.workbuddy/skills、.codebuddy/skills）。

GitHub 代理（可选）

如果搜索/部署连不上 GitHub，在这里填写你的代理地址（如 http://127.0.0.1:7890），留空则自动检测系统代理。
